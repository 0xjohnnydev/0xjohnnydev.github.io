# JF Tech LLC

JF Tech LLC is an Apple platform security research business operated by John (Johnny) Franks, its sole operator and security research lead, publicly known as **@0xjohnny** and previously **zeroxjf**.

The company conducts iOS and macOS vulnerability research, patch validation, and coordinated disclosure using owned Apple test devices and local test environments.
